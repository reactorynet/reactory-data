Core Philosophy

Why Build on Reactory?

Most platforms force you to write repetitive frontend boilerplate, manage build cycles, and wire enterprise plumbing. Reactory turns screens, APIs, and processes into declarative data definitions.

📑

Defined as Data

Screens are JSON Schema forms, components are addressable FQNs, and routes arrive dynamically from the server at boot. Update a user’s role or deploy a new screen instantly without a frontend build step.

⚡

Durable Saga Workflows

A resilient workflow engine that survives server restarts. Declaratively define steps, loops, parallel branches, external event triggers, and saga rollbacks using 35+ extensible step types.

🤖

Agentic AI Layer

AI sub-agents are first-class participants. Agents discover tools across filesystems, databases, and GraphQL schemas, inspect the living Neural System Graph, and mount real UI components into user chats.

sample.UserRegistrationForm@1.0.0.yaml
// Declarative UI: Shipped as data. No build step, no cache busting. id: core.UserRegistrationForm@1.0.0 uiFramework: material schema: type: object required: ["email", "firstName", "lastName"] properties: email: { type: "string", format: "email", title: "Email Address" } firstName: { type: "string", title: "First Name" } lastName: { type: "string", title: "Last Name" } tier: { type: "string", enum: ["Starter", "Professional", "Enterprise"] } uiSchema: ui:field: GridLayout ui:grid-layout: [ { email: { md: 12 } }, { firstName: { md: 6 }, lastName: { md: 6 } }, { tier: { md: 12, ui:widget: "radio" } } ]
Enterprise Architecture

Built-In Enterprise Capabilities

Everything needed to run mission-critical enterprise systems comes pre-wired, isolated, and production-tested.

🏢 Multi-Tenancy
Every request automatically resolves tenant contexts, database connections, themes, branding, and permissions.
🔐 4D Access Control
Granular RBAC scoped by Tenant × Organization × Business Unit × Role for true enterprise multi-org security.
🪪 Universal SSO
Local auth, JWT, Google, Microsoft Entra ID, GitHub, Okta, and SAML configured per tenant out of the box.
💾 Multi-Database
Simultaneous native support for MongoDB, PostgreSQL, MySQL, MSSQL, Redis, and external GraphQL/REST data sources.
🎨 Dynamic Theming
Material-UI v5 theme engine with instant light/dark mode switching and complete component-level overrides.
🔌 MCP Ready
Native Model Context Protocol support operating as both an MCP Server and an MCP Client for agentic workflows.
